## ⚡ 빠른 응답 보장 전략

### 1. 질문 패턴별 예상 시간

| 질문 유형 | 예시 | 예상 시간 | 시연 권장 |
|---------|-----|----------|---------|
| **제한 검색** | "상위 5개", "최근 3건" | 7-15초 | ✅ 강력 권장 |
| **간단 QA** | "언제 수리했나요?" | 10-20초 | ✅ 권장 |
| **문서 열람** | "XXX.pdf 보여줘" | 15-30초 | ⚠️ 주의 |
| **목록 조회** | "음향 10개" | 20-40초 | ⚠️ 가능 |
| **전체 나열** | "문서 전부" | 60-180초 | 🔴 절대 금지 |

### 2. 시연 시 절대 피해야 할 표현

🚫 **금지 워드**:
- "문서 전부 보여줘"
- "모든 문서"
- "전체 리스트"
- "다 알려줘"

→ **결과**: 2-3분 대기 (시연 분위기 깸)

### 3. 캐시 활용 전략

**2회 질의 패턴** (강력 추천):
```
1차: 2025년 구매한 방송 장비 상위 5개만
     → 10초 소요

[잠깐 설명]

2차: 2025년 구매한 방송 장비 상위 5개만 (동일 질문)
     → 0.05초! (캐시 히트, 200배 빠름)
```

**효과**: 캐시 성능 시연 + 빠른 호흡 유지

## 📋 검증된 시연 시나리오

### 시나리오 A: 기본 기능 (5분, 안전)

1. **검색** (~10초)
   ```
   Q: 2025년 구매한 장비 상위 3개만
   ```

2. **QA** (~15초)
   ```
   Q: 무선 마이크는 언제 수리했나요?
   ```

3. **캐시 시연** (~0.05초)
   ```
   Q: 2025년 구매한 장비 상위 3개만 (1번 반복)
   ```

**총 시간**: ~25초 (설명 시간 4분 30초 확보)

### 시나리오 B: 고급 기능 (7분, 중간)

1. **하이브리드 검색** (~15초)
   ```
   Q: 중계차 관련 최근 3건
   ```

2. **메타데이터 필터** (~20초)
   ```
   Q: 2024년 음향 장비 상위 5개
   ```

3. **의미 검색** (~18초)
   ```
   Q: 방송 송출용 모니터 장비
   ```

**총 시간**: ~53초 (설명 시간 6분 확보)

### 시나리오 C: 기술 시연 (3분, 고급)

1. **속도 비교**
   - 1차 질의: ~10초
   - 2차 질의 (캐시): ~0.05초
   - **강조**: "200배 빠른 응답!"

2. **오타 허용**
   ```
   Q: 무선 마익크 수리  (의도적 오타)
   ```
   → BM25가 "마이크" 자동 매칭

3. **복잡한 자연어**
   ```
   Q: 광화문에서 2025년에 교체한 장비
   ```
   → 쿼리 라우팅 + 하이브리드 검색 시연

## 🛡️ 비상 대응

### 질문이 너무 오래 걸릴 때

**증상**:
- 30초 이상 로딩
- `est. speed input: 5 toks/s` 이하

**조치**:
1. ⏸️ **중단 가능하면 중단** (Streamlit Stop 버튼)
2. 💬 "아, 이건 전체 목록이라 시간이 좀 걸리네요"
3. 🔄 **대체 질문으로 전환**:
   ```
   원래: 2025년 구매 장비 전체
   대체: 2025년 구매 장비 상위 3개만
   ```

### 시연 중 시스템 느려질 때

**원인**: 이전 질의의 VRAM 점유

**조치**:
1. 간단한 질문으로 전환
2. 캐시 질문 활용 (이전 질문 반복)
3. 1-2분 텀 두기 (VRAM GC 대기)
