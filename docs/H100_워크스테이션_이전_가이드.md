## 🚀 워크스테이션에서 따라할 순서

### Step 0: VS Code + Claude Code 설치 (10분)

#### 0-1. VS Code 설치
```bash
# Microsoft GPG 키 추가
wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > packages.microsoft.gpg
sudo install -D -o root -g root -m 644 packages.microsoft.gpg /etc/apt/keyrings/packages.microsoft.gpg

# VS Code 저장소 추가
sudo sh -c 'echo "deb [arch=amd64,arm64,armhf signed-by=/etc/apt/keyrings/packages.microsoft.gpg] https://packages.microsoft.com/repos/code stable main" > /etc/apt/sources.list.d/vscode.list'

# VS Code 설치
sudo apt update
sudo apt install -y code

# 설치 확인
code --version
```

#### 0-2. Claude Code CLI 설치
```bash
# Node.js 설치 (Claude Code 필수)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# Node.js 확인
node --version   # v20.x.x 이상이면 OK
npm --version

# Claude Code CLI 설치
npm install -g @anthropic-ai/claude-code

# 설치 확인
claude --version
```

#### 0-3. Claude Code 로그인
```bash
# 터미널에서 로그인 (브라우저 열림)
claude login

# 또는 API 키로 로그인
claude config set apiKey YOUR_API_KEY
```

#### 0-4. VS Code에서 Claude Code 연동
```bash
# VS Code 실행
code .

# VS Code 터미널(Ctrl+`)에서 Claude 실행
claude

# 이제 Claude Code 사용 가능!
```

**Tip**: VS Code Remote SSH로 워크스테이션에 원격 접속해서 사용할 수도 있음!

### Step 1: 기본 패키지 설치 (5분)
```bash
# 터미널 열고 복사-붙여넣기
sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl wget build-essential python3-pip python3-venv
```

### Step 2: CUDA 및 GPU 확인 (1분)
```bash
# GPU가 잘 인식되는지 확인
nvidia-smi

# 이렇게 나오면 성공:
# +-----------------------------------------------------------------------------+
# | NVIDIA-SMI 545.xx       Driver Version: 545.xx       CUDA Version: 12.4    |
# | GPU  Name        ...
# | NVIDIA H100 80GB HBM3
# +-----------------------------------------------------------------------------+
```

### Step 3: 프로젝트 다운로드 (2분)
```bash
# 홈 디렉토리로 이동
cd ~

# Git에서 프로젝트 가져오기
git clone https://github.com/YOUR_REPO/AI-CHAT.git
cd AI-CHAT

# 작업 브랜치로 전환
git checkout chore/ocr-dedup-v2-20251113
```

### Step 4: Python 가상환경 생성 (2분)
```bash
# 가상환경 만들기
python3 -m venv .venv

# 가상환경 활성화 (매번 터미널 열 때마다 해야 함)
source .venv/bin/activate

# 프롬프트가 (.venv) 로 시작하면 성공!
```

### Step 5: 기본 패키지 설치 (5분)
```bash
# pip 업그레이드
pip install --upgrade pip

# 기본 패키지 설치
pip install -r requirements.txt
```

### Step 6: vLLM 설치 (H100 전용) (3분)
```bash
# vLLM 설치 (H100 최적화 추론 엔진)
pip install vllm

# 확인
python -c "import vllm; print('vLLM 설치 완료!')"
```

### Step 7: Qwen2.5-72B 모델 다운로드 (30-60분)
```bash
# Hugging Face CLI 설치
pip install huggingface_hub

# 모델 다운로드 (약 40GB, 인터넷 속도에 따라 시간 소요)
huggingface-cli download Qwen/Qwen2.5-72B-Instruct-AWQ --local-dir ./models/qwen2.5-72b-awq

# 다운로드 중 진행률이 표시됨
# Downloading... 100%|████████████████| 40.0G/40.0G
```

### Step 8: 백업 파일 복원 (5분)
```bash
# USB나 네트워크에서 백업 파일 복사 후:
tar -xzvf ai-chat-backup.tar.gz

# docs/ 폴더와 var/ 폴더가 복원됨
ls docs/   # PDF 문서들 확인
ls var/    # DB 파일들 확인
```

### Step 9: 환경설정 수정 (3분)
```bash
# .env 파일 편집
nano .env

# 아래 내용 추가/수정:
# -----------------------------------------
LLM_BACKEND=vllm
VLLM_MODEL=./models/qwen2.5-72b-awq
LLM_MAX_TOKENS=4096
N_GPU_LAYERS=999
# -----------------------------------------

# 저장: Ctrl+O → Enter → Ctrl+X
```

### Step 10: 시스템 테스트 (5분)
```bash
# 테스트 실행
python -c "

print('LLM 로딩 테스트...')

print('테스트 완료!')
"
```

### Step 11: Streamlit 실행 (1분)

## 문제 해결 가이드

### "CUDA out of memory" 에러
```bash
# GPU 메모리 확인
nvidia-smi

# 다른 프로세스가 GPU 사용 중이면 종료
sudo fuser -v /dev/nvidia*
```

### "Module not found" 에러
```bash
# 가상환경 활성화 확인
source .venv/bin/activate

# 패키지 재설치
pip install -r requirements.txt
```

### vLLM 설치 실패
```bash
# CUDA 버전 확인
nvcc --version

# CUDA 12.4에 맞는 PyTorch 재설치
pip install torch==2.2.0 --index-url https://download.pytorch.org/whl/cu124
pip install vllm
```
