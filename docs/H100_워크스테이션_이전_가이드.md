# AI-CHAT 시스템 H100 워크스테이션 이전 가이드

> 초등학생도 따라할 수 있는 아주 자세한 가이드

# 전체 그림

```
[지금 쓰는 PC] → [USB/외장하드] → [새 H100 워크스테이션]
     ↓                ↓                    ↓
  백업하기         옮기기              설치하기
```

**목표**: 지금 PC의 AI-CHAT 시스템을 새 워크스테이션으로 옮기고, 더 좋은 AI 모델 사용하기

# PART 1: 지금 PC에서 할 일

## Step 1-1: 터미널 열기

### Windows의 경우:
1. 키보드에서 `Windows 키` + `R` 동시에 누르기
2. 작은 창이 뜨면 `wsl` 입력하고 `Enter` 누르기
3. 검은 화면(터미널)이 열림

### Mac의 경우:
1. `Command` + `Space` 눌러서 Spotlight 열기
2. `terminal` 입력하고 `Enter` 누르기

### Ubuntu의 경우:
1. `Ctrl` + `Alt` + `T` 동시에 누르기

---

## Step 1-2: AI-CHAT 폴더로 이동하기

터미널에 아래 글자를 **그대로** 입력하고 `Enter` 누르기:

```bash
cd ~/AI-CHAT
```

**확인하는 방법**:
```bash
pwd
```
입력하고 `Enter` 누르면 `/home/사용자이름/AI-CHAT` 이렇게 나오면 성공!

---

## Step 1-3: 코드를 GitHub에 올리기

아래 명령어를 **한 줄씩** 입력하고 매번 `Enter` 누르기:

```bash
git add -A
```
(몇 초 기다리기)

```bash
git commit -m "이전 전 백업"
```
(메시지가 나오면 성공)

```bash
git push
```
(업로드 진행률이 보이면 성공)

**만약 비밀번호를 물어보면**: GitHub 비밀번호 입력하고 `Enter`

---

## Step 1-4: 데이터 압축하기

### 방법 A: 자동 백업 스크립트 사용 (권장)

```bash
./scripts/ops/migrate_backup.sh /tmp/ai-chat-backup
```

이 스크립트가 자동으로:
- metadata.db 백업
- 텍스트 파일 압축
- PDF 문서 압축
- 인덱스 백업
- 체크섬 생성

### 방법 B: 수동 압축

터미널에 아래 명령어 입력하고 `Enter`:

```bash
tar -czvf ai-chat-backup.tar.gz metadata.db data/extracted/ docs/ var/ .env
```

**기다리기**: 파일이 많으면 5~10분 걸릴 수 있음. 화면에 파일 이름들이 쭉 지나가면 정상!

**완료 확인**:
```bash
ls -lh ai-chat-backup.tar.gz
```
파일 크기가 나오면 성공! (예: `2.5G` 또는 `500M` 등)

---

## Step 1-5: USB로 복사하기

### 방법 A: 파일 탐색기로 복사 (쉬운 방법)

1. USB 또는 외장하드를 PC에 꽂기
2. 파일 탐색기 열기 (Windows: `Windows키 + E`)
3. 왼쪽에서 `홈` → `AI-CHAT` 폴더 들어가기
4. `ai-chat-backup.tar.gz` 파일 찾기
5. 이 파일을 **마우스 오른쪽 클릭** → `복사`
6. USB 드라이브 클릭해서 들어가기
7. 빈 공간에서 **마우스 오른쪽 클릭** → `붙여넣기`
8. 복사 완료될 때까지 기다리기 (용량 따라 5~30분)

### 방법 B: 터미널로 복사

```bash
# USB 경로 확인 (보통 /mnt/usb 또는 /media/사용자이름/USB이름)
cp ai-chat-backup.tar.gz /mnt/usb/
```

---

## Step 1-6: USB 안전하게 빼기

1. 화면 오른쪽 아래 USB 아이콘 클릭
2. "안전하게 제거" 클릭
3. "제거해도 됩니다" 메시지 나오면 USB 빼기

**지금 PC에서 할 일 끝!**

## Step 2-9: USB에서 백업 파일 복원하기

### USB 꽂고 마운트하기

USB를 워크스테이션에 꽂기

USB 인식 확인:
```bash
lsblk
```
`sdb1` 또는 `sdc1` 같은 게 보이면 USB임

USB 마운트:
```bash
sudo mkdir -p /mnt/usb
sudo mount /dev/sdb1 /mnt/usb
```
(만약 `sdb1`이 아니면 `lsblk`에서 본 이름으로 바꾸기)

### 백업 파일 복사하기

```bash
cp /mnt/usb/ai-chat-backup.tar.gz ~/AI-CHAT/
```

### 압축 풀기

#### 자동 스크립트 사용 (권장):
```bash
./scripts/ops/migrate_restore.sh /mnt/usb/ai-chat-backup ~/AI-CHAT
```

#### 수동으로 압축 풀기:
```bash
cd ~/AI-CHAT
tar -xzvf ai-chat-backup.tar.gz
```

**확인**:
```bash
ls docs/
ls var/
ls data/extracted/
sqlite3 metadata.db "SELECT COUNT(*) FROM documents"
```
문서 수가 469개로 나오면 성공!

### USB 언마운트

```bash
sudo umount /mnt/usb
```

이제 USB 빼도 됨

# 문제 해결 가이드

## 에러: "command not found"

**원인**: 가상환경이 활성화 안 됨

**해결**:
```bash
source .venv/bin/activate
```
터미널 앞에 `(.venv)`가 보이는지 확인!

---

## 에러: "CUDA out of memory"

**원인**: GPU 메모리 부족

**해결**:
1. GPU 상태 확인:
   ```bash
   nvidia-smi
   ```
2. 다른 프로그램이 GPU 쓰고 있으면 종료:
   ```bash
   sudo fuser -v /dev/nvidia*
   ```

---

## 에러: "Module not found"

**원인**: 패키지가 설치 안 됨

**해결**:
```bash
source .venv/bin/activate
pip install -r requirements.txt
```

---

## 에러: "Permission denied"

**원인**: 권한 없음

**해결**:
명령어 앞에 `sudo` 붙이기:
```bash
sudo 원래명령어
```

---

## 웹페이지가 안 열림

**확인 1**: Streamlit이 실행 중인지
- 터미널에서 `Network URL: http://...` 메시지가 보여야 함

**확인 2**: 방화벽
```bash
sudo ufw allow 8501
```

**확인 3**: IP 주소 확인
```bash
hostname -I
```
나온 IP 주소로 다시 접속 시도
