### 슬라이드 7: 네이버 vs RAG
**레이아웃**: 프로세스 비교

```

[상단 - 네이버]
1. 검색어 입력 → 2. 웹페이지 찾음 → 3. 링크 보여줌
                                           ↓
                                    사용자가 직접 클릭

[하단 - RAG]
1. 질문 입력 → 2. 문서 찾음 → 3. AI가 읽고 정리 → 4. 답변
                                                      ↓
                                              바로 알려줌!

[비교표]
항목        | 네이버/구글    | RAG
결과        | 링크 리스트    | 답변
추가 작업   | 직접 읽어야 함 | 필요 없음
정보        | 어디 있는지    | 뭐라고 써있는지
시간        | 5-10분         | 5초

[하단 강조]
핵심 차이: "어디 있어?" vs "뭐라고 써있어?"
```
