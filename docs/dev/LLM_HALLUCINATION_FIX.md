# LLM Hallucination 문제 해결 보고서

**날짜**: 2025-11-20
**문제**: 짧은 문서에서 LLM이 "장비 운용자 평가 결과" 등 반복적인 텍스트를 과도하게 생성
**해결**: 프롬프트 템플릿 개선 + 동적 토큰 제한

---

## 🔍 문제 분석

### 증상
```
[누락 섹션]
3. 장비 운용자 평가 결과
4. 장비 운용자 평가 결과
5. 장비 운용자 평가 결과
... (50+ 반복)
```

### 근본 원인

#### 1. **프롬프트 템플릿 문제**
- **원인**: "누락된 섹션은 마지막에 '누락 섹션' 목록으로 제시한다" 지시
- **결과**: LLM이 없는 내용을 억지로 생성하려 시도

#### 2. **토큰 제한 문제**
- **원인**: 문서 1415자에 max_tokens=1500 설정
- **결과**: LLM이 남은 토큰을 채우려고 반복 패턴 생성

#### 3. **문서 선택 문제**
- **원인**: 유사한 이름의 문서 2개 중 잘못된 선택
  - 2023-08-11 문서 (DVR 없음) ← 선택됨
  - 2025-06-24 문서 (DVR 있음)

## ✅ 해결 방안

### 1. 프롬프트 템플릿 개선 (`app/prompts/document_prompts.py`)

**Before**:
```python
DETAILED_PROMPT = """
...
4) 누락된 섹션은 마지막에 '누락 섹션' 목록으로 제시한다.
...
"""
```

**After**:
```python
DETAILED_PROMPT = """
...
[중요 제약사항 - 반드시 준수]
- 제공된 근거 패시지에 명시적으로 기술된 내용만을 사용한다
- 근거에 없는 내용은 생성, 추론, 반복, 확장하지 않는다
- 섹션이 근거에 없으면 "해당 섹션 없음"만 표기하고 넘어간다
- 답변이 짧더라도 근거 범위를 벗어나지 않는다
- 동일 내용을 반복하거나 패턴을 생성하지 않는다
...
"""
```

### 2. 동적 토큰 제한 (`app/rag/pipeline.py`)

**추가된 로직**:
```python
# 동적 토큰 제한: 문서 길이에 따라 조정하여 hallucination 방지
content_length = len(full_text)
if detailed_mode:
    # 상세 모드: 문서 길이의 1/3 정도로 제한 (최대 1500)
    adjusted_tokens = min(max_tokens, max(300, content_length // 3))
else:
    # 일반 모드: 문서 길이의 1/4 정도로 제한 (최대 800)
    adjusted_tokens = min(max_tokens, max(200, content_length // 4))

logger.debug(f"토큰 조정: 원본 {max_tokens} → {adjusted_tokens} (문서 {content_length}자)")
```

**효과**:
| 문서 길이 | 모드 | 원래 토큰 | 조정된 토큰 | 결과 |
|----------|------|----------|------------|------|
| 1415자 | detailed | 1500 | 471 | ✅ 반복 방지 |
| 3000자 | detailed | 1500 | 1000 | ✅ 적절한 제한 |
| 500자 | qa | 800 | 200 | ✅ 간결한 답변 |
| 2000자 | qa | 800 | 500 | ✅ 적절한 길이 |

## 🎯 영향 범위

### 개선되는 케이스
1. **짧은 문서**: 과도한 토큰으로 인한 반복 생성 방지
2. **불완전 문서**: 없는 섹션을 억지로 생성하지 않음
3. **일반 QA**: 문서 길이에 맞는 적절한 답변 길이

### 부작용 없음
- 긴 문서는 여전히 충분한 토큰 할당
- 요약 모드는 별도 로직으로 처리
- 기존 정상 동작 케이스 영향 없음

### 2. Hallucination 감지 시스템 (미구현)
```python
def detect_hallucination(text: str) -> bool:
    # 반복 패턴 감지
    lines = text.split('\n')
    seen = {}
    for line in lines:
        if line in seen:
            seen[line] += 1
            if seen[line] > 3:
                return True
        else:
            seen[line] = 1
    return False
```
