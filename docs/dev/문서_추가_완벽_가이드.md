# 📝 문서 추가 완벽 가이드 (초보자용)

## **1단계: 파일 준비**
컴퓨터에 추가할 PDF 파일을 준비합니다.
- 예: `2025-11-21_새로운_장비_구매_건.pdf`

---

## **2단계: incoming 폴더에 파일 복사**

**방법 A - 파일 탐색기 사용 (Windows/Mac)**
1. `AI-CHAT` 폴더 열기
2. `docs` 폴더 열기
3. `incoming` 폴더 열기
4. 준비한 PDF 파일을 여기에 **복사** (드래그 앤 드롭)

**방법 B - 명령어 사용 (터미널)**
```bash
# AI-CHAT 폴더에서 실행
cp /경로/파일명.pdf docs/incoming/
```

예시:
```bash
cp ~/Downloads/2025-11-21_새로운_장비_구매_건.pdf docs/incoming/
```

---

## **3단계: 파일이 제대로 들어갔는지 확인**

터미널에서:
```bash
ls docs/incoming/
```

출력 예시:
```
2025-11-21_새로운_장비_구매_건.pdf
```

---

## **4단계: 문서 등록 스크립트 실행**

터미널에서 (AI-CHAT 폴더에서):
```bash
python3 scripts/ingest_from_docs.py
```

**성공 메시지 예시:**
```
✅ 성공: 1
처리 중: 2025-11-21_새로운_장비_구매_건.pdf
  ✓ success (150ms)
이동: ... → docs/year_2025/...
  →year_2025
```

**실패 시 확인:**
- `🔁 중복: 1` → 이미 같은 파일이 등록되어 있습니다
- `❌ 실패: 1` → 파일 형식 오류 또는 시스템 문제
- `→kept_in_incoming` → DB 저장 실패, 파일은 incoming에 유지됨

---

## **5단계: 확인**

1. **파일이 year 폴더로 이동했는지 확인:**
```bash
ls docs/year_2025/ | grep 2025-11-21
```

2. **DB에 등록되었는지 확인:**
```bash
sqlite3 metadata.db "SELECT filename FROM documents WHERE filename LIKE '%2025-11-21%';"
```

3. **웹에서 확인:**
   - 브라우저에서 웹 페이지 새로고침 (F5)
   - 문서 라이브러리 탭에서 새 문서 확인

---

## **6단계: 검색 인덱스 업데이트 (선택사항)**

문서를 검색 가능하게 하려면:
```bash
python3 scripts/quick_rebuild_bm25.py
```

완료까지 약 2-3분 소요됩니다.

---

## ⚠️ **주의사항**

### ❌ **하지 말아야 할 것:**
- `docs/year_2025/` 폴더에 **직접** 파일 복사
- `docs/processed/` 폴더 건드리기
- ingest 스크립트 실행 없이 파일만 추가

### ✅ **반드시 해야 할 것:**
1. `docs/incoming/`에 파일 복사
2. `python3 scripts/ingest_from_docs.py` 실행
3. 성공 메시지 확인

## 🔄 **중복 파일 처리**

**이미 등록된 문서를 다시 넣으면:**
- 파일명이 정규화되어 비교됩니다
  - `2025-11-21_카메라_렌즈_구매_건.pdf`
  - `2025-11-21_카메라렌즈_구매건(1).pdf`
  - → **같은 문서로 인식되어 중복 처리됨**

**중복 처리 시:**
```
🔁 중복: 1
status=duplicate
→kept_in_incoming  # 파일은 incoming에 유지
```

**해결 방법:**
- 중복이 맞다면: incoming에서 파일 삭제
- 실제로 다른 문서라면: 파일명을 명확하게 구분되도록 수정

---

## 📏 **파일명 규칙**

### ✅ **권장 형식:**
```
YYYY-MM-DD_설명_건.pdf
```

**예시:**
- `2025-11-21_카메라_렌즈_구매_건.pdf` ✅
- `2024-08-15_중계차_보수_검토서.pdf` ✅

### ❌ **비권장 형식:**
- `새문서.pdf` ❌ (날짜 없음 → `processed/`로 이동)
- `문서_2025.pdf` ❌ (날짜 형식 불일치)
- `20251121_문서.pdf` ❌ (구분자 없음)

**날짜 없는 파일명의 경우:**
- 처리는 되지만 `docs/processed/`로 이동
- 연도별 필터링/조회에서 제외됨
- 웹 UI의 연도 탭에 표시 안 될 수 있음

**규칙을 따르면 자동으로:**
- 날짜 추출
- 연도별 폴더 분류 (`year_2025/`)
- 검색 최적화
- 웹 UI 정상 표시

## 🔄 **한 번에 여러 파일 추가하기**

```bash
# 1. 여러 파일을 incoming에 복사
cp ~/Downloads/*.pdf docs/incoming/

# 2. 한 번에 모두 등록
python3 scripts/ingest_from_docs.py

# 3. 확인
ls docs/incoming/  # 비어있어야 함 (모두 year_YYYY로 이동됨)
```

## 🆘 **문제 해결**

### **Q: ingest 실행 후 incoming에 파일이 그대로 있어요**
**A:** `→kept_in_incoming` 메시지 확인
- DB 저장 실패
- 로그에서 오류 메시지 확인
- 웹 서버 실행 중이면 중지 후 재시도

### **Q: 웹에서 문서가 안 보여요**
**A:** 순서대로 확인:
1. `ls docs/year_2025/` - 파일이 있는지
2. `sqlite3 metadata.db "SELECT * FROM documents WHERE filename='파일명';"` - DB에 있는지
3. 브라우저 강력 새로고침 (Ctrl+F5)
4. 웹 서버 재시작

### **Q: 검색이 안 돼요**
**A:** 검색 인덱스 재빌드 필요:
```bash
python3 scripts/quick_rebuild_bm25.py
```

## 📊 **시스템 상태 확인**

**파일 시스템 vs DB 개수 비교:**
```bash
# 2025년 파일 개수
find docs/year_2025 -name "*.pdf" | wc -l

# DB에 등록된 2025년 문서 개수
sqlite3 metadata.db "SELECT COUNT(*) FROM documents WHERE year='2025';"
```

두 개수가 다르면 동기화 문제가 있는 것입니다.

## 💡 **베스트 프랙티스**

1. **파일명은 항상 날짜로 시작**
   - `YYYY-MM-DD_` 형식 준수

2. **한글 설명은 명확하게**
   - `카메라_구매_건` (O)
   - `카메라` (X)

3. **특수문자 최소화**
   - `()`, `&` 사용 가능
   - `#`, `@`, `%` 지양

4. **정기적인 인덱스 재빌드**
   - 여러 문서 추가 후 한 번에 실행
   - 야간 배치 등록 고려

5. **백업**
   - `metadata.db` 정기 백업
   - `docs/year_YYYY/` 폴더 백업
