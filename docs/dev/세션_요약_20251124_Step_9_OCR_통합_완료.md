## 신규 아키텍처

### 1. `app/rag/ocr/pipeline.py` - 공통 OCR 파이프라인

**핵심 함수**:
- `ocr_extract_pdf()`: PDF → 이미지 → Tesseract OCR
  - DPI 설정 가능 (기본 300)
  - 진행 상황 콜백 지원
  - 페이지별 텍스트 구분
  
- `update_document_text()`: DB 업데이트
  - `sqlite_helpers.connect_metadata()` 사용 (v2.1 호환)
  - 트랜잭션 지원
  - FTS5 자동 동기화 (트리거)

### 2. `app/rag/ocr/selectors.py` - 문서 선택기

**4가지 선택 모드**:
- `select_by_text_length()`: text_preview < threshold
- `select_by_avg_per_page()`: (text_len / page_count) < threshold
- `select_zero_text()`: text_preview = 0 또는 NULL
- `select_from_file_list()`: 파일 목록에서 읽기

### 3. `scripts/ops/ocr_reprocess.py` - 통합 CLI

**사용법**:
```bash
# 텍스트 < 100자 문서
python scripts/ops/ocr_reprocess.py --mode poor --threshold 100

# 페이지당 평균 < 300자 문서
python scripts/ops/ocr_reprocess.py --mode average --threshold 300

# 0자 문서만
python scripts/ops/ocr_reprocess.py --mode zero

# 파일 목록에서 읽기
python scripts/ops/ocr_reprocess.py --mode list --file-list targets.txt

# Dry-run 모드 (시뮬레이션)
python scripts/ops/ocr_reprocess.py --mode poor --dry-run

# 최대 개수 제한
python scripts/ops/ocr_reprocess.py --mode poor --limit 10

# DPI 설정
python scripts/ops/ocr_reprocess.py --mode poor --dpi 400
```
