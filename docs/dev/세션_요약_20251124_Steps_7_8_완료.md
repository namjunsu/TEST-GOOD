### Step 7: Transaction 패턴 적용 분석

**목표**: `metadata_txn()` 컨텍스트 매니저를 ingest/reindex 스크립트에 적용

**분석 결과**:
1. `app/data/metadata_db.py` 현재 구조:
   - `MetadataDB` 클래스 사용 (thread-local 연결 관리)
   - `_cursor()` 컨텍스트 매니저로 자동 commit/rollback
   - 각 `add_document()` 호출이 독립적인 트랜잭션

2. `scripts/core/ingest_from_docs.py` 구조:
   - 파일별로 `add_document()` 호출 (line 484)
   - FTS 동기화는 SQLite 트리거가 자동 처리
   - 각 파일이 독립적으로 처리됨

3. **문제 분석**:
   - `MetadataDB.__init__` (line 36): `isolation_level="DEFERRED"` 사용
   - DEFERRED는 첫 SQL 실행까지 트랜잭션 시작 지연
   - `app/utils/sqlite_helpers.py`의 `connect_metadata()`는 이미 WAL + autocommit + busy_timeout 설정됨

**결론**:
- 대규모 리팩토링 불필요
- `MetadataDB`가 `sqlite_helpers.connect_metadata()`를 사용하도록 변경하는 것이 가장 간단
- 이렇게 하면 모든 DB 연결이 WAL + 일관된 설정 사용
