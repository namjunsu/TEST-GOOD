## ✅ 해결 과정

### 1단계: 누락 문서 발견
```bash
# 파일시스템 vs DB 비교
ls -1 docs/year_2025/*.pdf | wc -l  # 19개
sqlite3 metadata.db "SELECT COUNT(*) FROM documents WHERE path LIKE 'docs/year_2025/%';"  # 15개
```

### 2단계: 문서 추가
```bash
# 1. incoming 폴더로 복사
cp docs/year_2025/2025-01-14_채널A_불용_방송_장비_폐기_요청의_건.pdf docs/incoming/
cp docs/year_2025/2025-02-14_케이블_보호_보드(옐로우자켓)_구매_건.pdf docs/incoming/
cp docs/year_2025/2025-08-13_TVLogic_모니터_구매_검토서.pdf docs/incoming/

# 2. 인제스트 실행
python3 scripts/ingest_from_docs.py

# 결과: 3개 문서가 year_정보 없 폴더로 이동됨 (잘못된 경로!)
```

### 3단계: 경로 수정
```bash
# 1. 파일 이동
mv "docs/year_정보 없/2025-01-14_채널A_불용_방송_장비_폐기_요청의_건.pdf" "docs/year_2025/"
mv "docs/year_정보 없/2025-02-14_케이블_보호_보드(옐로우자켓)_구매_건.pdf" "docs/year_2025/"
mv "docs/year_정보 없/2025-08-13_TVLogic_모니터_구매_검토서.pdf" "docs/year_2025/"

# 2. DB 경로 업데이트
sqlite3 metadata.db "UPDATE documents SET path = 'docs/year_2025/2025-01-14_채널A_불용_방송_장비_폐기_요청의_건.pdf' WHERE path = 'year_정보 없/2025-01-14_채널A_불용_방송_장비_폐기_요청의_건.pdf';"
# (나머지 2개도 동일)
```

### 4단계: date 컬럼 업데이트

## 📚 교훈 및 개선 사항

### 발견된 문제점
1. **`ingest_from_docs.py`의 날짜 파싱 실패**
   - 파일명에서 날짜를 추출하지 못하면 "정보 없" 처리
   - → `year_정보 없` 폴더로 이동하여 경로 문제 발생

2. **`year` 컬럼과 `date` 컬럼 불일치**
   - `date`는 업데이트되었지만 `year`는 "정보 없" 상태 유지
   - `document_loader.py`는 `year` 컬럼만 참조하여 연도 파싱

3. **자동화 부족**
   - 수동으로 여러 단계를 거쳐야 문서 추가 완료
   - → `add_new_document.sh` 스크립트로 해결

### 향후 개선 방안
1. **`ingest_from_docs.py` 개선**
   - 파일명에서 날짜 추출 로직 강화
   - 날짜 파싱 실패 시에도 올바른 폴더로 이동 (파일명 패턴 기반)

2. **`year` 컬럼 자동 동기화**
   - DB 트리거 또는 후처리로 `date`에서 `year` 자동 추출
   - `UPDATE` 트리거로 `date` 변경 시 `year`도 자동 업데이트

3. **웹 인터페이스에서 문서 추가 기능**
   - Streamlit UI에서 직접 PDF 업로드 가능하도록 개선
