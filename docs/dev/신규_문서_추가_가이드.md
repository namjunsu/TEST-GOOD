# 신규 문서 추가 가이드

## 📋 표준 프로세스

### 방법 1: 자동 파이프라인 (권장)

신규 PDF 문서를 자동으로 처리하여 시스템에 추가합니다.

```bash
# 1. incoming 폴더에 PDF 파일 복사
cp /path/to/새문서.pdf docs/incoming/

# 2. 자동 인제스트 스크립트 실행
python scripts/ingest_from_docs.py

# 3. 결과 확인
# - 문서가 metadata.db에 추가됨
# - 텍스트가 data/extracted/에 추출됨
# - PDF가 연도별 폴더(docs/year_YYYY/)로 이동됨
```

**처리 과정:**
1. **텍스트 추출**: pdfplumber + Tesseract OCR
2. **메타데이터 파싱**: 파일명, 날짜, 카테고리, 기안자 등
3. **DB 저장**: metadata.db에 레코드 추가
4. **파일 이동**: 연도별 폴더로 자동 정리

### 방법 2: 수동 DB 추가 (긴급/특수 케이스)

특수한 경우 DB에 직접 추가할 수 있습니다.

```python
#!/usr/bin/env python3
import sqlite3
from pathlib import Path

# DB 연결
conn = sqlite3.connect("metadata.db", isolation_level=None)
conn.execute("PRAGMA journal_mode=WAL")
cursor = conn.cursor()

# 텍스트 파일 읽기 (있으면)
txt_path = Path("data/extracted/파일명.txt")
if txt_path.exists():
    text_preview = txt_path.read_text(encoding='utf-8')[:500]
else:
    text_preview = "문서 제목"

# 새 문서 추가
cursor.execute("""
    INSERT INTO documents (
        path, filename, title, date, year, month, category,
        drafter, amount, file_size, page_count, text_preview,
        keywords, doctype, display_date, normalized_filename
    ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
""", (
    'year_2025/2025-01-01_문서명.pdf',  # path
    '2025-01-01_문서명.pdf',             # filename
    '문서 제목',                          # title
    '2025-01-01',                        # date
    '2025',                              # year
    '2025-01',                           # month
    '구매',                               # category
    '',                                   # drafter
    0,                                    # amount
    1234567,                             # file_size (bytes)
    2,                                    # page_count
    text_preview,                        # text_preview
    '["키워드1", "키워드2"]',             # keywords (JSON)
    'disposal',                          # doctype
    '2025-01-01',                        # display_date
    '2025-01-01_문서명.pdf'              # normalized_filename
))

doc_id = cursor.lastrowid
print(f"✅ 문서 추가: ID={doc_id}")

# FTS 인덱스 추가
cursor.execute("""
    INSERT INTO documents_fts(rowid, path, title, text_preview, keywords)
    SELECT id, path, title, text_preview, keywords
    FROM documents WHERE id = ?
""", (doc_id,))

conn.commit()
conn.close()

# WAL 체크포인트
import subprocess
subprocess.run(['sqlite3', 'metadata.db', 'PRAGMA wal_checkpoint(FULL);'])
```

## 🐛 근본 원인 분석 (TVLogic 사례)

### 발견된 문제

**문제:** TVLogic 문서가 ingest 시 "성공" 메시지가 나오지만 DB에 저장되지 않음

**근본 원인 (2025-11-21 확인):**

**🔴 Critical Bug: `scripts/ingest_from_docs.py` 경로 계산 오류**

- **위치**: `ingest_from_docs.py:440`
- **문제**: 상대 경로를 절대 경로에 대해 `relative_to()` 호출
- **에러 메시지**: `'docs/processed/파일명.pdf' is not in the subpath of '/home/wnstn4647/AI-CHAT/docs'`

```python
# Before (버그):
final_path = self.processed_dir / pdf_path.name  # "docs/processed/..." (상대)
doc_metadata = {
    "path": str(final_path.relative_to(Path.cwd() / "docs")),  # ❌ 실패!
    ...
}

# After (수정):
final_path = self.processed_dir / pdf_path.name
final_path_abs = final_path.resolve()  # 절대 경로로 변환
docs_dir_abs = (Path.cwd() / "docs").resolve()
doc_metadata = {
    "path": str(final_path_abs.relative_to(docs_dir_abs)),  # ✅ 성공
    ...
}
```

**영향**:
- DB 저장 실패 → 파일이 `incoming/`에 남음
- ingest 로그에 `db_failed()` 표시
- `status = "success"`는 여전히 설정됨 (잘못된 통계)

**이전에 발견된 부수 문제들:**

1. **`utils/document_loader.py`의 SELECT 쿼리가 불완전**
   - `created_at`, `title`, `page_count` 등 필드가 누락됨
   - 웹 UI의 "최근 10건"은 `created_at`을 사용하는데 없었음
   - ✅ **해결됨**: 2025-11-20에 SELECT 쿼리 확장

2. **start_ai_chat.sh의 BM25 가드가 수동 문서 삭제**
   - `scripts/reindex_atomic.py`가 DB를 전체 재구축
   - 디스크의 PDF 파일 기반으로만 재인덱싱
   - 수동으로 DB에 추가한 레코드는 제외됨
   - ✅ **해결됨**: `SKIP_BM25_GUARD=1` 플래그 추가

### 해결 방법

#### ✅ Fix 1: document_loader.py 수정 (2025-11-20 완료)

