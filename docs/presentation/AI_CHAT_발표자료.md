## 슬라이드 6: RAG 쉽게 이해하기

### RAG = "똑똑한 사서 + AI 비서"

```
📚 비유로 이해하기

┌─────────────────────────────────────────┐
│  일반 ChatGPT                           │
│  = 책 없는 선생님                        │
│  → 학습한 것만 알고 있음                 │
│  → 우리 회사 문서는 전혀 모름            │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│  우리 RAG 시스템                         │
│  = 도서관 사서                           │
│  → 우리 문서를 찾아서 읽고 답변          │
│  → 어떤 문서에서 찾았는지도 알려줌       │
└─────────────────────────────────────────┘
```

---

## 슬라이드 7: RAG vs 일반 AI 비교

| 구분 | 일반 ChatGPT | 우리 RAG 시스템 |
|------|-------------|-----------------|
| **지식 범위** | 인터넷 일반 지식 | 우리 회사 문서 |
| **정확도** | 추측/환각 가능 | 문서 기반으로 정확 |
| **출처** | 없음 | 어떤 문서에서 찾았는지 표시 |
| **보안** | 데이터 외부 전송 | 로컬에서 처리 (보안 유지) |
| **비용** | API 사용료 발생 | 무료 (로컬 실행) |

```
└─────────────────────────────────────────┘
```

## 슬라이드 9: 내부 처리 과정 (기술 참고용)

### 질문에서 답변까지

```
사용자 질문
    ↓
┌─────────────────┐
│ 1. 질문 분석    │ ← 무엇을 찾는지 파악
│   (쿼리 라우팅) │   검색? 비용? 요약?
└────────┬────────┘
         ↓
┌─────────────────┐
│ 2. 문서 검색    │ ← 키워드 + 의미 검색
│   (하이브리드)  │   두 가지 방법 조합
└────────┬────────┘
         ↓
┌─────────────────┐
│ 3. 순위 결정    │ ← 가장 관련 있는 문서
│   (리랭킹)      │   상위 5개 선택
└────────┬────────┘
         ↓
┌─────────────────┐
│ 4. 답변 생성    │ ← 로컬 AI가 문서 읽고
│   (LLM)         │   답변 + 출처 생성
└────────┬────────┘
         ↓
    답변 + 출처 표시
```
