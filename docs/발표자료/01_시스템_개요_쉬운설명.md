# 📚 AI 문서 검색 시스템 - 쉬운 설명서

**작성일**: 2024년 11월 24일
**대상**: 초보자 및 팀원 발표용

---

## 🎯 이 시스템이 하는 일

**간단히 말하면**: PDF 문서들을 자동으로 읽어서, 나중에 필요한 내용을 쉽게 찾을 수 있게 해주는 시스템입니다.

### 예시
- 직원: "2023년 방송장비 구매 건 찾아줘"
- 시스템: 관련 문서 3개를 찾아서 보여줌 + AI가 요약해서 답변

---

## 📊 현재 상태 (2024-11-24 기준)

| 항목 | 수치 |
|------|------|
| 📄 보관 중인 문서 | 475개 |
| 📅 연도 범위 | 2014년 ~ 2025년 |
| 🗂️ 문서 종류 | 구매 검토서, 폐기 요청서, 수리 건 등 |
| ⚡ 검색 속도 | 약 1초 이내 |

---

## 🏗️ 시스템 구조 (3단계로 이해하기)

```
┌─────────────────────────────────────────────┐
│  1단계: 문서 입력                              │
│  PDF 파일 → 텍스트 추출 → DB 저장              │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│  2단계: 검색 인덱스 구축                        │
│  저장된 문서 → 검색용 인덱스 생성                │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│  3단계: 사용자 검색                            │
│  질문 입력 → 관련 문서 찾기 → AI 답변 생성      │
└─────────────────────────────────────────────┘
```

## 📁 주요 폴더 설명

### 💾 데이터 폴더
```
docs/
├── incoming/          ← 새 문서를 여기에 넣으면 자동 처리
├── year_2025/        ← 2025년 문서 보관함
├── year_2024/        ← 2024년 문서 보관함
└── rejected/         ← 처리 실패한 문서
```

### 🔧 핵심 코드 폴더
```
app/
├── api/              ← 웹 API 서버 (검색 요청 처리)
├── data/             ← 데이터베이스 관리
├── rag/              ← 검색 엔진 (문서 찾기)
└── llm/              ← AI 답변 생성
```

### ⚙️ 관리 도구
```
scripts/
├── ingest_from_docs.py    ← 새 문서 추가 (가장 중요!)
├── reindex_atomic.py      ← 검색 인덱스 재구축
├── backup_db.sh           ← 데이터 백업
└── check_fs_vs_db.py      ← 상태 점검
```

### 📝 설정 파일
```
config/
├── document_processing.yaml  ← 문서 처리 규칙
├── llm_config.yaml          ← AI 설정
└── domain_synonyms.yaml     ← 검색어 동의어 사전
```

## 🚀 주요 작업 방법

### 1️⃣ 새 문서 추가하기
```bash
# 1. PDF 파일을 incoming 폴더에 복사
cp 새문서.pdf docs/incoming/

# 2. 문서 추가 스크립트 실행
python3 scripts/ingest_from_docs.py

# 결과: 자동으로 연도별 폴더로 정리됨
```

### 2️⃣ 검색 인덱스 업데이트
```bash
# 문서 추가 후 검색이 안 될 때
python3 scripts/reindex_atomic.py
```

### 3️⃣ 시스템 시작하기
```bash
# 서버 시작 (포트 7860, 8501)
bash start_ai_chat.sh

# 브라우저에서 접속
http://localhost:8501
```

### 4️⃣ 백업하기
```bash
# 데이터베이스 백업
bash scripts/backup_db.sh

# 백업 파일 위치: backups/ 폴더
```

## 💡 자주 묻는 질문 (FAQ)

### Q1: 문서를 추가했는데 검색이 안 돼요
**A**: 검색 인덱스를 업데이트하세요
```bash
python3 scripts/reindex_atomic.py
```

### Q2: 시스템이 느려졌어요
**A**: 서버를 재시작하세요
```bash
# 1. 기존 프로세스 종료
pkill -f uvicorn
pkill -f streamlit

# 2. 재시작
bash start_ai_chat.sh
```

### Q3: 데이터가 날아갔어요!
**A**: 백업에서 복원하세요
```bash
bash scripts/restore_db.sh
```

### Q4: 몇 개 문서가 있는지 확인하려면?
**A**: 상태 점검 스크립트 실행
```bash
python3 scripts/check_fs_vs_db.py
```

## 📈 시스템 동작 흐름도

```
사용자가 PDF 업로드
        ↓
ingest_from_docs.py 실행
        ↓
1. PDF에서 텍스트 추출 (PyPDF2)
2. 문서 정보 파싱 (날짜, 제목, 작성자)
3. 데이터베이스 저장 (metadata.db)
4. 연도별 폴더로 이동
        ↓
reindex_atomic.py 실행
        ↓
검색 인덱스 구축 (BM25)
        ↓
웹 인터페이스에서 검색 가능!
```

## 📝 발표 시 강조할 포인트

### ✅ 시스템의 장점
1. **자동화**: PDF 넣으면 알아서 처리
2. **빠른 검색**: 475개 문서에서 1초 이내 검색
3. **AI 답변**: 단순 검색이 아닌 요약된 답변 제공
4. **연도별 분류**: 자동으로 연도 파악하여 정리

### ⚠️ 주의사항
1. **백업 필수**: 매주 `backup_db.sh` 실행
2. **인덱스 업데이트**: 문서 추가 후 반드시 `reindex_atomic.py` 실행
3. **디스크 용량**: 문서가 많아지면 공간 확인
4. **로그 정리**: `logs/` 폴더가 너무 커지지 않도록 주기적 삭제
