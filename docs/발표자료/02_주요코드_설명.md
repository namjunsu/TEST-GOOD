class BM25Store:

## 🔧 scripts/ 폴더 - 관리 도구들

### 1. `ingest_from_docs.py` - 새 문서 추가 (가장 중요!)
**역할**: incoming 폴더의 PDF를 자동 처리

```python
# 실행 순서:
# 1. docs/incoming/ 폴더에서 PDF 파일 찾기
# 2. PDF에서 텍스트 추출
# 3. 문서 제목에서 날짜 파싱 (예: 2024-05-10)
# 4. 문서 종류 분류 (구매/폐기/수리)
# 5. metadata.db에 저장
# 6. 연도별 폴더로 이동
```

**처리 과정**:
```
2024-05-10_장비구매검토서.pdf
    ↓ [텍스트 추출]
"구매 승인 요청..."
    ↓ [정보 파싱]
날짜: 2024-05-10
종류: 구매 검토서
    ↓ [DB 저장]
ID=123, filename=..., year=2024
    ↓ [파일 이동]
docs/year_2024/로 이동
```

**실행 방법**:
```bash
python3 scripts/ingest_from_docs.py
```

**중요도**: ⭐⭐⭐⭐⭐ (문서 추가의 핵심!)

### 2. `reindex_atomic.py` - 검색 인덱스 재구축
**역할**: DB의 모든 문서를 읽어서 검색 인덱스 다시 만들기

```python
# 작동 방식:
# 1. metadata.db에서 전체 문서 읽기 (475개)
# 2. 각 문서의 텍스트로 BM25 인덱스 구축
# 3. var/index/bm25_index.pkl에 저장
# 4. 완료!
```

**언제 실행?**:
- 새 문서를 추가한 후
- 검색이 안 될 때
- DB를 복원한 후

**실행 시간**: 약 2분 (475개 문서 기준)

**중요도**: ⭐⭐⭐⭐ (검색 업데이트 필수!)

**크기**: 3.1MB
**형식**: SQLite
**테이블**:
```sql
documents (
    id INTEGER,           -- 문서 ID
    filename TEXT,        -- 파일명
    path TEXT,           -- 파일 경로
    year TEXT,           -- 연도
    category TEXT,       -- 카테고리
    content TEXT,        -- 텍스트 내용
    created_at DATETIME  -- 등록일
)
```

**중요도**: ⭐⭐⭐⭐⭐ (절대 삭제 금지!)

## 🚦 start_ai_chat.sh - 서버 시작 스크립트
