## 슬라이드 2: 시스템 개요

### 🎯 시스템 목적
**PDF 문서를 자동으로 관리하고 빠르게 찾을 수 있게 해주는 시스템**

### 주요 기능
✅ PDF 자동 분류 및 저장
✅ 빠른 검색 (1초 이내)
✅ AI 기반 답변 생성
✅ 연도별 자동 정리

### 현재 상태
- **문서 수**: 475개
- **연도 범위**: 2014년 ~ 2025년 (12년)
- **문서 종류**: 구매, 폐기, 수리 관련 문서

---

## 슬라이드 3: 왜 이 시스템이 필요한가?

### ❌ 기존 방식의 문제점
```
📁 수백 개의 PDF 파일
  └─ 원하는 문서 찾기 어려움
  └─ 파일명으로만 검색 가능
  └─ 내용 검색 불가
  └─ 수작업으로 분류 필요
```

### ✅ 시스템 도입 후
```
🔍 자동 분류 + 내용 검색
  └─ 키워드로 빠른 검색
  └─ 연도별 자동 정리
  └─ AI가 요약 답변
  └─ 관련 문서 추천
```

**Q1**: "문서 개수가 늘어나면 느려지나요?"
