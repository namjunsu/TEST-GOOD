
### 실제 동작 흐름

```
1. 사용자 질문
   ↓
2. 어떤 종류의 질문인지 분석 (검색? 요약? 질답? 비용?)
   ↓
3. 관련 문서 찾기 (BM25 검색 엔진)
   ↓
4. 결과 정리 (메타데이터 추가)
   ↓
5. AI 답변 생성 (필요시)
   ↓
6. 사용자에게 반환
```

**핵심**: 사람이 직접 찾을 필요 없음!

## 슬라이드 8: 검색 메커니즘 상세

### 3단계 하이브리드 검색

#### Stage 0: ExactMatch (정확 일치)
```python
쿼리: "HRD-1234 모델 찾아줘"
→ 모델 코드 DB에서 정확 일치 검색
→ 즉시 반환 (0.1초)
```

#### Stage 1: SQLite FTS5 (전문 검색)
```python
쿼리: "중계차 카메라"
→ LLM으로 쿼리 확장: "중계차 + 카메라 + 렌즈 + OB VAN"
→ SQLite FTS5 본문 검색
→ 관련성 순 정렬
```

#### Stage 2: BM25 보충 검색
```python
FTS5 결과 < 10개인 경우
→ BM25 알고리즘으로 추가 검색
→ 재현율(Recall) 향상
```

### 검색 정확도

| 지표 | 값 |
|------|-----|
| **정확도** (Precision) | ~90% |
| **재현율** (Recall) | ~85% |
| **평균 응답 시간** | 0.3~5초 |
