### 😊 쉽게 설명하는 방법

#### 비유 사용
- **시스템 = 도서관**
  - PDF 파일 = 책
  - metadata.db = 도서 카드
  - 검색 인덱스 = 책 뒤의 색인(index)
  - AI = 사서(책 내용 요약해주는)

#### 실생활 예시
```
발표자: "여러분, 지난주에 작성한 보고서 파일 찾을 때
```

## 📊 예상 질문 및 답변

### 자주 나오는 질문 TOP 10

**Q1**: 문서가 얼마나 많아도 되나요?
> **A**: 현재 475개이고, 10,000개까지는 문제없습니다. 그 이상은 서버 업그레이드가 필요합니다.

**Q2**: 설치가 어렵나요?
> **A**: 이미 설치되어 작동 중입니다. 새로 설치할 필요 없습니다.

**Q3**: 워드나 엑셀 파일도 되나요?
> **A**: 현재는 PDF만 지원합니다. 필요하다면 향후 추가 가능합니다.

**Q4**: 비용이 얼마나 드나요?
> **A**: AI API 비용으로 월 약 $20 (약 26,000원) 정도입니다.

**Q5**: 누가 관리하나요?
> **A**: 대부분 자동화되어 있어서 주 1회 백업만 실행하면 됩니다.

**Q6**: 외부에서도 접속 가능한가요?
> **A**: 현재는 사내 네트워크만 가능합니다. 외부 접속은 보안 검토 후 가능합니다.

**Q7**: 이미지나 스캔 문서는요?
> **A**: OCR 기능이 있어서 스캔 문서도 처리 가능합니다.

**Q8**: 검색이 정확한가요?
> **A**: 테스트 결과 약 90% 이상의 정확도를 보입니다.

**Q9**: 느려지진 않나요?
> **A**: 현재 1초 이내 응답 속도를 유지하고 있습니다.

**Q10**: 데이터 백업은?
> **A**: 매주 자동 백업되며, backups/ 폴더에 4주치 보관됩니다.

```

   → http://localhost:8501

2. 검색창에 입력
   → "2024년 방송장비"

3. 결과 보여주기
   → 관련 문서 3개 표시
   → AI 답변 보여주기

   → PDF 내용 확인
```

**강조 포인트**: "키워드만 입력하면 관련 문서를 즉시 찾아줍니다"

### 시나리오 2: 새 문서 추가 (3분)

```
1. 준비된 PDF 파일 보여주기
   → "2024-11-20_테스트문서.pdf"

2. incoming 폴더에 복사
   → cp test.pdf docs/incoming/

3. 처리 스크립트 실행
   → python3 scripts/ingest_from_docs.py

4. 결과 확인
   → "문서가 자동으로 2024년 폴더로 이동되었습니다"
   → 검색해서 찾기
```

**강조 포인트**: "PDF 파일만 넣으면 자동으로 연도 분류, 내용 추출, 저장까지 완료됩니다"
