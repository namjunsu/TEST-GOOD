### 2. metadata.db의 text_preview 갱신 (선택)
**문제**: DB 쿼리 결과와 실제 상태 불일치

**해결 방법**:
```sql
-- 1. txt 파일 기반으로 text_preview 갱신
UPDATE documents
SET text_preview = (
    SELECT substr(content, 1, 500)
    FROM (
        SELECT readfile('data/extracted/' || filename || '.txt') as content
        FROM documents d2
        WHERE d2.id = documents.id
    )
)
WHERE EXISTS (
    SELECT 1 FROM (
        SELECT 1
        WHERE file_exists('data/extracted/' || documents.filename || '.txt')
    )
);
```

**권장**: 보류
- 실제 검색 동작에는 영향 없음 (BM25는 txt 파일 기반)
- text_preview는 UI 표시용일 뿐
- 재인덱싱 시 자동 갱신되도록 스크립트 수정이 더 나은 선택
